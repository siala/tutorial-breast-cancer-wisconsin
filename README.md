This is a simple illustration of streamlit (https://streamlit.io/) using the UCI Breast Cancer Wisconsin (Diagnostic) dataset https://archive.ics.uci.edu/dataset/17/breast-cancer-wisconsin-diagnostic.

The app is available online at [tutorial-breast-cancer-wisconsin.streamlit.app](https://tutorial-breast-cancer-wisconsin.streamlit.app)

The source code is on GitHub at https://github.com/siala/tutorial-breast-cancer-wisconsin

The source code is designed to be simple and self contained. It was successfully tested with python 3.13.

To run the code locally, you need to install the python packages in requirements.txt and the softwares in packages.txt.

The main entry file is main_breast_cancer.py.
